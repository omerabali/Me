## 📖 Proje Hakkında (English Overview below)

**Farm Pal**, geleneksel hayvancılık operasyonlarını dijital ortama taşıyan, **Yapay Zeka** destekli profesyonel bir yönetim sistemidir. Hayvan sağlığı takibi, detaylı üretim analizleri ve finansal yönetimi tek bir platformda toplayarak işletme verimliliğini maksimize etmeyi amaçlar.

## 🛠 Kullanılan Teknolojiler (Tech Stack)

| Alan | Teknoloji | Değer Önerisi |
| :--- | :--- | :--- |
| **Logic Layer** | `React` + `TypeScript` | Güvenli ve ölçeklenebilir bileşen mimarisi. |
| **Aesthetics** | `Tailwind CSS` + `Shadcn UI` | Modern ve tutarlı kullanıcı arayüzü tasarımı. |
| **Infrastructure** | `Supabase` (PostgreSQL) | Gerçek zamanlı veri yönetimi ve güvenlik. |
| **Automation** | `Resend` | Yüksek iletilebilirlik oranına sahip e-posta sistemi. |
| **Mobile Runtime** | `Capacitor` | Tek kod tabanıyla Android ve iOS platform desteği. |

## 🚀 Kurulum (Setup)

### 1. Hazırlık
Depoyu klonlayın ve bağımlılıkları yükleyin:
```bash
git clone https://github.com/omerabali/farm-pal.git
cd farm-pal
npm install
```

### 2. Çevresel Değişkenler
`.env` dosyasına anahtarlarınızı ekleyin:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

### 3. Çalıştırma
```bash
npm run dev
```

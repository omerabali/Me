Personal Portfolio Website

Bu proje kişisel portfolyo web sitesi tasarımıdır. HTML, CSS ve JavaScript kullanılarak geliştirilmiş modern, responsive ve animasyonlu bir web arayüzü sunar. Tasarım; ana sayfa, profil alanı, çalışma süreçleri ve sosyal medya bağlantılarını içeren bölümlerden oluşur.

 Özellikler

Responsive tasarım (mobil, tablet ve masaüstü uyumlu)

Typewriter efekti ile dinamik başlık animasyonu

Animate.css entegrasyonu sayesinde yumuşak animasyonlar

Font Awesome ikonları

Temiz ve düzenli HTML/CSS yapısı

Kolay özelleştirilebilir proje yapısı

## 🚀 The Vision: Engineering Habit Formation

Language acquisition is often hindered by friction and inconsistent engagement. **Lexis** addresses this problem not just with content, but through a scientifically-driven experience designed to integrate seamlessly into a user's digital life.

At its core, Lexis is an exercise in **Cognitive Optimization**. By leveraging Spaced Repetition Systems (SRS), it ensures that learning is not a "task," but a subconscious progression.

## ✨ Key Value Propositions

### 🧠 Adaptive Retention Engine
Traditional learning ignores the forgetting curve. Lexis embraces it.
*   **Intelligent Pacing:** Dynamically adjusts interval timing based on recall accuracy.
*   **High-Impact Curation:** Focuses on 30 daily words to maximize retention while minimizing burnout.

### 🎮 Behavioral Hook Architecture
We’ve implemented psychological triggers derived from gamification theory to transform discipline into desire.
*   **Growth Visualization:** Real-time feedback loops via leaderboards and streaks.
*   **Milestone Achievements:** Validating progress through tiered digital signaling.

### 📊 Precision Analytics
Data-driven transparency. Users can visualize their vocabulary growth through high-fidelity insights, moving from "feeling" progress to "measuring" it.

## 🛠 Technical Architecture & Stack

Lexis is built with a focus on **Fluidity, Security, and Scalability.** Every architectural choice was made to ensure a native, low-latency experience.

| Component | Stack | Rationale |
| :--- | :--- | :--- |
| **Mobile Core** | React Native (Expo) | Single codebase efficiency with native-grade performance across ecosystem boundaries. |
| **Persistence Layer** | Supabase | Leverages PostgreSQL power with Row Level Security (RLS) for enterprise-grade data integrity. |
| **State Orchestration** | Context API | Lean state management for high-frequency UI updates without unnecessary overhead. |
| **Offline Reliability** | AsyncStorage | Ensures learning continuity regardless of connectivity status through local caching strategies. |

## ⚡ Deployment & Local Setup

### 1. Environment Preparation
```bash
git clone https://github.com/username/lexis.git
cd lexis
npm install
```

### 2. Infrastructure Linkage
Initialize your backend by configuring `utils/supabaseClient.js` with your production or staging credentials.

### 3. Execution
```bash
npm start
```
